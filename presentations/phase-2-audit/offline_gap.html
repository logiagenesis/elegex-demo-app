07 / WP5 READINESS

OFFLINE IS NOT YET A PRODUCT CAPABILITY

The present foreman experience sends direct mutations to the server. UI optimism is not an offline guarantee.
The existing implementation is a connected workflow with an optimistic interface—not a reboot-surviving write-ahead system.
Current path
Foreman actions call server mutations directly.
Missing persistence
No IndexedDB queue exists to survive an app kill or device reboot.
Missing safety
No client-generated idempotency UUID prevents duplicated replay.
Missing causality
No dependency graph enforces check-in before materials and completion.
Operational implication: a network interruption can prevent field work from becoming a durable job artifact.
