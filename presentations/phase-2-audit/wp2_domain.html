THE DOMAIN

The product moves from a generic USD/UTC workspace toward the actual operating context of a South African electrical contractor.
Product specificity is configuration, not hardcoded presentation copy.
Domain area Generic baseline WP2 schema foundation
Regional settings USD and UTC defaults `en-ZA`, `ZAR`, and `Africa/Johannesburg` are organization-level settings.
Call-out pricing Generic fixed service values Tenant-scoped temporal call-out types preserve rate history through active-date ranges.
Contracting relationships One generic contact model Clients distinguish domestic, commercial, body corporate, estate/development, and managing agent; billing and site contacts can differ.
Implementation boundary: this establishes the schema and migration foundation. User-facing settings controls and historical-rate application still require subsequent implementation and verification.
